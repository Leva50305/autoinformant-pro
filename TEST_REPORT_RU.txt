AutoInformant Pro 2.0.2 — отчёт проверок
Дата сборки: 2026-11-02

1. Компиляция и полный набор unit-тестов
--------------------------------------
Команда:
  python -m py_compile AutoInformant.py informant_core.py openomsi_bridge.py pack_system.py yandex_music_service.py test_autoinformant.py test_yandex_music.py
Результат: PASS.

Команда:
  python -m unittest -q test_autoinformant.py test_yandex_music.py
Результат: 95/95 тестов PASS.

В том числе проверены:
- импорт внешнего аудиофайла внутрь активного профиля `.aipack` в `_AutoInformantCustom`;
- запись относительного пути в `manifest.json`, без сохранения абсолютного пути к компьютеру;
- повторное открытие установленного пака и разрешение файла по манифесту;
- экспорт `.aipack` с импортированным аудиофайлом и ссылкой в `manifest.json`;
- выбор файла, уже находящегося в активном профиле, без копирования/дублирования;
- назначение в активный профиль категории транспорта вместо базового профиля карты;
- сохранение Unicode-имени файла.

2. GUI smoke test — контекстное меню и операции переназначения
-------------------------------------------------------------
Окно приложения создано под Xvfb с виртуальным экраном 1366x768. Создание главного окна
прошло без исключений; дерево остановок и PackManager инициализированы.

Контекстное меню ПКМ проверено на реальной строке остановки. В меню присутствуют два
варианта:
- «Выбрать из активного аудиопака…»;
- «Выбрать на компьютере и импортировать в пак…».

Обработчики проверены с тестовым `.aipack` и подменёнными файловыми диалогами:
- внешний WAV выбран с диска, скопирован в `_AutoInformantCustom`, назначение сохранено;
- WAV, выбранный из ресурсов активного профиля, привязан относительным путём без копии.
Результат обработчиков: PASS.

3. Совместимость и целостность
------------------------------
- Формат `.aipack` schema v1 сохранён; миграция пакетов не требуется.
- Пользовательские настройки schema v12 сохранены; миграция не требуется.
- Lua-плагин и протокол v2 не изменялись. Переустанавливать/обновлять плагин ради 2.0.2 не нужно.
- Три поставляемых `.aipack` сохранены без изменения байтов.
- В ZIP не включаются `autoinformant_pro_settings.json`, пользовательский токен Яндекса и локальные логи.
- В пользовательские `overrides` больше не записывается абсолютный путь при ручном переназначении через ПКМ. Без доступного эффективного профиля пака операция останавливается с подсказкой.

4. Не проверено в этой среде
----------------------------
- Реальный файловый диалог Windows Explorer и поведение на разных версиях Windows/DPI.
- Реальное воспроизведение выбранного пользовательского аудиофайла внутри запущенного Windows/openOMSI.
- Поведение на пользовательском установленном паке с нестандартными структурами ресурсов, которые не входят в тестовые фикстуры.

Причина: среда сборки Linux/Xvfb. Автотесты и GUI-smoke подтверждают механику сохранения пакета и наличие/вызов UI-команд, но окончательное прослушивание и проверка Windows Explorer требуют Windows/openOMSI.

Итог:
95/95 unit-тестов, компиляция модулей, создание GUI, проверка контекстного меню и оба
варианта переназначения пройдены. Формат `.aipack` v1 и Lua-протокол v2 сохранены.
