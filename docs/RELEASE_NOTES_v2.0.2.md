# AutoInformant Pro 2.0.2

Переназначение аудио остановок прямо внутри активного `.aipack`: файл можно выбрать
из ресурсов пака или импортировать с компьютера — без абсолютных путей в настройках.

## Что нового

- В контекстном меню остановки (ПКМ) команда **«Назначить аудиофайл»** предлагает два действия:
  **выбрать из активного аудиопака** или **выбрать на компьютере и импортировать в пак**.
- Файл, уже находящийся внутри профиля, записывается в `manifest.json` относительным путём без копии.
- Внешний файл копируется в `<asset_root>/_AutoInformantCustom/` с уникальным безопасным именем;
  кириллица в имени сохраняется.
- При активной категории транспорта назначение попадает в категорию, а не в базовый профиль карты.
- Убрано тихое сохранение внешнего абсолютного пути в `autoinformant_pro_settings.json`.
- Схема `.aipack` v1, настройки v12 и Lua-протокол v2 не менялись — плагин обновлять не нужно.

## Установка

1. Скачайте `AutoInformantPro_Standalone_v2_0_2.zip` ниже и распакуйте в папку приложения.
2. Не удаляйте `autoinformant_pro_settings.json`, `packs/installed` и свои данные.
3. Запустите `run_app.bat` — зависимости установятся автоматически.
4. Аудиопаки: **Аудиопаки → Импортировать .aipack** или возьмите готовые из
   [репозитория паков](https://github.com/Leva50305/autoinformant-pro-audio-packs).
